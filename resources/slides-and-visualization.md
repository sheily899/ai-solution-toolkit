# 演示与可视化

## Visual Explainer

- 原始地址：https://github.com/nicobailon/visual-explainer
- 用途：把架构、Diff、计划、数据表和项目复盘生成自包含 HTML 页面。
- 适用阶段：方案说明、技术沟通、评测复盘和作品集展示。
- 计划实践：把 AskData 的 Trace 与失败归因生成可视化页面。
- 状态：待实践

## Frontend Slides

- 原始地址：https://github.com/zarazhangrui/frontend-slides
- 用途：从零生成或转换 HTML 演示文稿，并通过视觉预览选择风格。
- 适用阶段：客户 PoC 汇报、项目答辩和面试案例表达。
- 我的实践：已用于作品集与展示材料探索。
- 状态：已实践

## HTML Slide Skill Directory

- 原始地址：https://tosea.ai/slide-skills
- 用途：对比不同 HTML 演示 Skill 及其原始仓库。
- 使用原则：只按明确场景选择，不批量安装。
- 状态：已体验
