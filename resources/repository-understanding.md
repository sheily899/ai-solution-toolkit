# 仓库理解

## DeepWiki

- 原始地址：https://deepwiki.com/
- 官方说明：https://docs.devin.ai/work-with-devin/deepwiki
- 用途：为公开 GitHub 仓库生成文档、架构图和基于源码的问答。
- 适用阶段：开源项目调研、代码理解和面试准备。
- 计划实践：梳理 AskData 的路由、Schema 检索、SQL 生成和执行链路。
- 核验方法：所有关键结论回到源文件、函数和运行 Trace 检查。
- 状态：待实践

## GitDiagram

- 原始地址：https://gitdiagram.com/
- 开源仓库：https://github.com/ahmedkhaleel2004/gitdiagram
- 用途：把 GitHub 仓库转换为可交互结构图。
- 适用阶段：快速理解代码结构、制作架构图底稿。
- 使用边界：仓库结构不等于业务流程，需要人工重组和简化。
- 状态：待实践
