# AI Solution Toolkit

面向 **AI 解决方案、实施交付与客户成功** 场景的资源与实践工具箱。

这里不追求收集最多的 AI 工具，而关注它们能否帮助完成一条真实工作链路：

> 需求澄清 → 场景判断 → PoC 设计 → 方案验证 → 评测复盘 → 交付表达

## 收录标准

每项资源至少回答：

1. 它解决什么问题？
2. 适合工作链路中的哪个阶段？
3. 我是否实际使用过？
4. 使用结果和边界是什么？
5. 原始来源在哪里？

状态统一使用：**待体验 / 已体验 / 已实践 / 已沉淀**。

## 项目边界

本仓库中的个人项目目前以学习、原型和公开 Demo 为主。模拟业务背景会明确标注，不将其描述为真实客户上线案例；涉及效果的数据，以仓库中的测试范围、评测记录和可复现证据为准。

## 更新原则

- 优先链接原始仓库、官方文档与一手案例。
- 不搬运文章全文，只记录来源、摘要与个人实践。
- 不以 Star 数量替代质量判断。
- 第三方 Skill 使用前检查代码、权限、依赖和安全风险。
- 未经实践的资源不标记为“已掌握”。
